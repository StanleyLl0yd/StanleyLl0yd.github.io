PurposeЗадача

Less cleanup after copying.Меньше исправлений после копирования.

Text copied from PDFs, documents or websites can contain broken paragraphs, split words and stray spaces. CopyFix cleans those artifacts locally, without sending the copied text to an online service.Текст из PDF, документов или сайтов может содержать разорванные абзацы, перенесённые слова и лишние пробелы. CopyFix исправляет эти артефакты локально, без передачи текста внешнему сервису.

How it worksКак пользоваться

Copy. Review. Paste.Скопировать. Проверить. Вставить.

1

Copy textСкопируйте текст

Use the ordinary Copy command in a PDF reader, browser or document. CopyFix does not continuously watch the clipboard.Скопируйте текст в PDF-просмотрщике, браузере или документе. CopyFix не следит за буфером постоянно.

2

Run cleanupЗапустите исправление

Press the configurable Ctrl+Alt+F9 shortcut or use the tray menu. When needed, a native two-column preview highlights changes.Нажмите настраиваемое сочетание Ctrl+Alt+F9 или выберите команду в трее. При необходимости нативное окно покажет изменения в двух колонках.

3

Paste or undoВставьте или отмените

Accept the reviewed result and paste normally. One guarded Undo can restore the prior plain text before anything new is copied.Подтвердите проверенный результат и вставьте текст. Однократная защищённая отмена может вернуть прежний обычный текст до следующего копирования.

Privacy and controlsПриватность и контроль

Your clipboard stays on your PC.Буфер обмена остаётся на компьютере.

CopyFix works offline, requires no account or backend and does not save clipboard history, log copied content or send text across the network. It has no OCR, spelling correction, AI rewriting or automatic pasting. Preferences are stored in the current user's Windows Registry, not INI files.CopyFix работает офлайн, не требует учётной записи или сервера, не сохраняет историю буфера, не записывает его содержимое и не передаёт текст по сети. В приложении нет OCR, исправления орфографии, ИИ-переписывания или автоматической вставки. Настройки хранятся в реестре текущего пользователя Windows, а не в INI-файлах.

Clipboard replacement is not atomic in Windows. Accepting a preview for rich-text content replaces other formats with plain Unicode text; Undo cannot restore original HTML or RTF. The app checks for clipboard changes, but paragraph joins and hyphenation are heuristic: review important edits before accepting.Замена содержимого буфера в Windows не атомарна. При подтверждении исправления форматированный текст заменяется обычным Unicode; отмена не восстановит исходные HTML или RTF. Приложение проверяет, не изменился ли буфер, но объединение строк и переносов остаётся эвристическим: важные изменения нужно проверять перед принятием.

Verification and availabilityПроверки и доступность

Native code. Measured checks.Нативный код. Проверяемые результаты.

CopyFix is built with C++20, Win32 and system RichEdit. The Windows x64 Release build uses a static MSVC runtime and produces one portable EXE. Automated validation passed nine Windows test suites and three Clang ASan/UBSan suites. The owner reported 15 of 15 functional and UX checks as passed.CopyFix написан на C++20 с использованием Win32 и системного RichEdit. Сборка Windows x64 Release использует статический MSVC runtime и создаёт один портативный EXE. Пройдены девять наборов тестов Windows и три набора Clang ASan/UBSan. Автор подтвердил успешность всех 15 функциональных и интерфейсных проверок.

The owner also reported successful tests on clean and working Windows 10/11 machines; exact OS build numbers and a standalone runtime inventory were not documented. Official version 1.0.0 has been published on GitHub with one unsigned portable EXE.
