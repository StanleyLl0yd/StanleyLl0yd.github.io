ArchitectureАрхитектура

One authoritative Rust core.Одно авторитетное Rust-ядро.

Version 0.9.4 completed a major internal consolidation: move legality, capture and house topology, release/scoring, replay validation and deterministic AI search now live in one shared Rust game-core.В версии 0.9.4 завершено крупное внутреннее объединение: допустимость ходов, топология захватов и домов, освобождение и счёт, проверка повторов и детерминированный поиск ИИ теперь живут в одном общем Rust-ядре game-core.

The web/PWA build runs that core through optimized WebAssembly; native Tauri builds link the same crate directly. TypeScript is intentionally limited to session, persistence, worker and UI orchestration — fewer duplicated rules means fewer ways for platforms to disagree.Браузерная PWA запускает это ядро через оптимизированный WebAssembly, а нативные Tauri-сборки подключают тот же Rust-модуль напрямую. TypeScript намеренно ограничен сессией, хранением, Web Worker и управлением интерфейсом — меньше дублирования правил означает меньше возможностей для расхождения платформ.

Offline by designОфлайн по замыслу

The board is the product — not an account.Продукт — это игровое поле, а не аккаунт.

Game state, preferences and viewport data are local. The PWA works offline, supports controlled updates and keeps the same rules as the native builds. English and Russian are built in.Состояние партии, настройки и параметры поля хранятся локально. PWA работает офлайн, управляемо обновляется и использует те же правила, что и нативные сборки. Русский и английский встроены.

The release pipeline verifies the web build, Rust dependency graph and native artifacts, including Android 16 KB ELF alignment and universal macOS architecture checks. The technical work is deliberately aimed at preserving gameplay, not changing it for its own sake.Релизный конвейер проверяет веб-сборку, граф Rust-зависимостей и нативные артефакты, включая выравнивание ELF для страниц памяти 16 КБ на Android и универсальную архитектуру macOS. Технические изменения специально направлены на сохранение поведения игры, а не на изменение ради изменения.
