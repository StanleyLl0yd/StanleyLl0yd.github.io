Tray-firstРабота из трея

Small footprint, useful controls.Компактно, но с нужными настройками.

Everon lives in the Windows system tray instead of keeping a main window open. It provides live timer status, quick presets, a global hotkey, optional notifications and startup with Windows.Everon живёт в системном трее Windows вместо постоянного главного окна. Там доступны текущий статус таймера, быстрые пресеты, глобальная горячая клавиша, уведомления и автозапуск.

It can also send F15, F16 or F17 at a configurable interval when that behavior is explicitly enabled. Manual lock, sleep, sign-out and shutdown commands are never intercepted.При явном включении утилита также может отправлять F15, F16 или F17 с заданным интервалом. Ручная блокировка, сон, выход из системы и выключение никогда не перехватываются.
