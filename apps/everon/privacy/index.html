Privacy PolicyПолитика конфиденциальности

Last updated: September 3, 2026Последнее обновление: 3 сентября 2026 г.

Everon is a portable native Windows utility that prevents automatic sleep while it is enabled.Everon — портативная нативная утилита Windows, предотвращающая автоматический сон, пока она включена.

Data collectionСбор данных

Everon does not require a user account, cloud service, advertising service or analytics service for its functionality. Its keep-awake, timer, hotkey, notification and optional synthetic-key features operate locally through Windows APIs.Для работы Everon не требуются учётная запись, облачный сервис, реклама или аналитический сервис. Предотвращение сна, таймеры, горячая клавиша, уведомления и опциональные синтетические клавиши работают локально через API Windows.

Local settingsЛокальные настройки

Application settings are stored for the current Windows user under HKCU\Software\Everon. This includes preferences needed to restore configured behavior such as timer, power, hotkey, notification, language and autostart settings.Настройки приложения хранятся для текущего пользователя Windows в HKCU\Software\Everon. Там находятся параметры, необходимые для восстановления выбранного поведения: таймеров, питания, горячей клавиши, уведомлений, языка и автозапуска.

Autostart and inputАвтозапуск и ввод

If Start with Windows is enabled, Everon registers the executable path for the current user. If synthetic F15, F16 or F17 input is enabled, those key events are generated locally through Windows and are not sent to a remote Everon service.Если включён запуск вместе с Windows, Everon регистрирует путь к исполняемому файлу для текущего пользователя. Если включены синтетические F15, F16 или F17, эти события создаются локально средствами Windows и не отправляются в удалённый сервис Everon.

External linksВнешние ссылки

The About dialog contains links to the official Everon website and this Privacy Policy. Everon opens a selected link through Windows in the user's configured handler, normally a web browser. Any processing performed by that external application or destination is governed by its own privacy practices.В разделе «О программе» есть ссылки на официальный сайт Everon и эту политику конфиденциальности. Выбранная ссылка передаётся Windows и открывается настроенным обработчиком пользователя, обычно браузером. Дальнейшая обработка определяется правилами конфиденциальности этого приложения или сайта.

ChangesИзменения

If Everon's data practices change, this Privacy Policy will be updated before or together with the corresponding application release.Если порядок работы Everon с данными изменится, эта политика конфиденциальности будет обновлена до выхода соответствующего релиза или одновременно с ним.

ContactКонтакты

For privacy questions or bug reports, use the Everon project repository.По вопросам конфиденциальности и для сообщений об ошибках используйте репозиторий проекта Everon.
