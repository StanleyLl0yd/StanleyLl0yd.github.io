Cross-platform coreКроссплатформенное ядро

One game engine across web and native builds.Одно игровое ядро для браузера и нативных сборок.

The authoritative rules, win detection and AI live in a shared Rust core. The browser build executes it through WebAssembly; Android and macOS call the same implementation through Tauri 2.Авторитетные правила, определение победы и ИИ находятся в общем Rust-ядре. Браузерная версия выполняет его через WebAssembly, а Android и macOS обращаются к той же реализации через Tauri 2.

TypeScript is intentionally limited to UI orchestration, rendering caches, persistence and sharing. That removes duplicate rule and AI implementations while keeping gameplay, history, replay and share formats consistent across targets.TypeScript намеренно отвечает только за управление интерфейсом, кэширование отрисовки, хранение и обмен. Это устраняет дублирование правил и ИИ, сохраняя единое поведение игры, истории, повторов и формата обмена на всех платформах.

Product detailsДетали продукта

Built to disappear behind the game.Технологии, которые не мешают игре.

The UI supports system, light and dark themes plus English and Russian. Result sounds and haptics are optional, and the web build remains installable as an offline PWA with controlled update notification.Интерфейс поддерживает системную, светлую и тёмную темы, а также русский и английский языки. Звук и вибрация результата опциональны, а браузерная версия устанавливается как офлайн-PWA и сообщает о доступных обновлениях.

There is no account, analytics, advertising or tracking. Game state stays local unless the player explicitly shares a position, while deterministic Rust regressions protect the common rules and AI behavior.Здесь нет аккаунта, аналитики, рекламы или отслеживания. Состояние игры остаётся локальным, пока игрок сам не решит поделиться позицией, а детерминированные регрессионные тесты Rust защищают общие правила и поведение ИИ.
