Cross-platform coreКроссплатформенное ядро

One game engine across web and native builds.Одно игровое ядро для web и native.

The authoritative rules, win detection and AI live in a shared Rust core. The browser build executes it through WebAssembly; Android and macOS use the same core inside a Tauri 2 native shell.Авторитетные правила, определение победы и ИИ находятся в общем Rust-ядре. Web-версия выполняет его через WebAssembly, а Android и macOS используют то же ядро внутри нативной оболочки Tauri 2.

That architecture keeps gameplay consistent across platforms while the browser remains installable as an offline PWA. There is no account, analytics, advertising or tracking; game state stays local unless the player explicitly shares a position.Такая архитектура сохраняет одинаковое поведение игры на всех платформах, а браузерная версия устанавливается как офлайн-PWA. Нет аккаунта, аналитики, рекламы и трекинга; состояние игры остаётся локальным, пока игрок сам не решит поделиться позицией.

Product detailsДетали продукта

Built to disappear behind the game.Технологии, которые не мешают игре.

The UI supports system, light and dark themes plus English and Russian. Result sounds and haptics are optional, and the web build includes an offline lifecycle with update notification instead of silently replacing the running game.Интерфейс поддерживает системную, светлую и тёмную темы, а также русский и английский языки. Звук и вибрация результата опциональны, а PWA корректно работает офлайн и сообщает о доступном обновлении вместо незаметной подмены запущенной игры.

AI work is kept off the browser UI thread and validated by deterministic regression coverage — the implementation is designed so responsiveness and reproducibility are part of the product, not afterthoughts.Работа ИИ вынесена из UI-потока браузера и покрыта детерминированными регрессионными проверками — отзывчивость и воспроизводимость здесь являются частью продукта, а не поздней оптимизацией.
