Privacy by designПриватность по замыслу

A security utility that does not need your data.Утилита безопасности, которой не нужны ваши данные.

⌁

No product networkingБез сетевых функций

Generation, analysis and settings stay local on every platform. Android requests no INTERNET permission, and the desktop apps contain no product networking.Генерация, анализ и настройки на всех платформах остаются локальными. Android не запрашивает INTERNET, а настольные версии не содержат сетевых функций продукта.

◇

Native cryptographic RNGsСистемные криптографические ГСЧ

Android uses SecureRandom, Windows uses BCryptGenRandom and macOS uses SecRandomCopyBytes, while the same generation rules are preserved across platforms.Android использует SecureRandom, Windows — BCryptGenRandom, macOS — SecRandomCopyBytes; правила генерации остаются едиными на всех платформах.

◎

No ads or analyticsБез рекламы и аналитики

No analytics, tracking SDKs, advertising identifiers or cloud account are part of the app.В приложении нет аналитики, SDK отслеживания, рекламных идентификаторов или облачного аккаунта.

⌘

Rules that fit the targetПравила под конкретную задачу

Choose 4–64 characters, enabled groups, ambiguous-character exclusion and duplicate handling, with 16/24/32 quick presets.Выбирайте длину 4–64, группы символов, исключение неоднозначных знаков и повторов; есть быстрые варианты 16/24/32.

▰

Strength analysisАнализ стойкости

The indicator considers length and variety as well as sequences, repetition, repeated blocks and common weak patterns.Индикатор учитывает не только длину и разнообразие, но и последовательности, повторы, повторяющиеся блоки и типовые слабые шаблоны.

◐

Native platform UIНативный интерфейс платформы

Material 3 on Android, Win32/Common Controls on Windows and AppKit on macOS, with English and Russian localization and no cross-platform runtime UI framework.Material 3 на Android, Win32/Common Controls в Windows и AppKit в macOS, русский и английский интерфейс без кроссплатформенного UI-фреймворка времени выполнения.

Sensitive-data handlingРабота с чувствительными данными

Generated means temporary.Сгенерировано — значит временно.

Generated passwords live only in process memory and are never persisted. Only non-secret preferences are stored locally using Android DataStore, the current-user Windows Registry or macOS UserDefaults; the product has no cloud sync or backend, and Android application backup remains disabled.Сгенерированные пароли находятся только в памяти процесса и никогда не сохраняются. Локально хранятся лишь несекретные настройки: в Android DataStore, пользовательском разделе реестра Windows или macOS UserDefaults; облачной синхронизации и сервера у продукта нет, резервное копирование данных Android-приложения отключено.

When a password is explicitly revealed, each native app enables the strongest practical platform screen-capture exclusion available. Clipboard cleanup is scheduled after 60 seconds and clears only Password Generator's still-current value, without overwriting newer clipboard content.При явном показе пароля каждая нативная версия включает максимально доступную на своей платформе защиту от захвата экрана. Очистка буфера планируется через 60 секунд и удаляет только всё ещё актуальное значение Password Generator, не затрагивая более новое содержимое буфера.
