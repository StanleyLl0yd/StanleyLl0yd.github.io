Four refresh modesЧетыре режима

All tabs, current window, all except the current tab, or the current tab only. Choose from the toolbar or keyboard shortcut.Все вкладки, текущее окно, все кроме активной или только активная. Выбор из меню расширения или горячей клавишей.

◎

Website exclusionsИсключения сайтов

Skip selected domains and subdomains in every refresh mode. Useful for forms, chats and other pages where unsaved work matters.Пропускайте выбранные домены и поддомены во всех режимах. Особенно полезно для форм, переписок и страниц с несохранёнными данными.

◷

Optional timerТаймер по желанию

Schedule refreshes every 1–1440 minutes. Chromium alarms are approximate, especially during sleep or browser suspension.Настройте интервал от 1 до 1440 минут. Таймер Chromium приблизительный, особенно при сне или приостановке браузера.

InstallationУстановка

Install from the verified GitHub release.Установите расширение из релиза GitHub.

1

Download and extractСкачайте и распакуйте

Download the official v1.9 ZIP and extract it to a permanent folder. You can compare its digest against SHA256SUMS.txt.Скачайте официальный ZIP версии 1.9, распакуйте в постоянную папку. Контрольную сумму можно сверить с SHA256SUMS.txt.

2

Load unpackedЗагрузите распакованное

Open chrome://extensions (or your Chromium extension manager), enable Developer mode and select Load unpacked, then the folder with manifest.json.Откройте chrome://extensions (либо страницу расширений вашего браузера), включите режим разработчика и выберите «Загрузить распакованное», затем папку с manifest.json.

3

Configure and useНастройте и используйте

Open extension options for the mode, timer and exclusions. When updating, reuse the same folder and click Reload to preserve the extension ID and settings.В параметрах выберите режим, таймер и исключения. При обновлении используйте ту же папку и нажмите «Обновить», чтобы сохранить ID расширения и настройки.

Privacy and limitsПриватность и ограничения

No analytics or remote backend.Без аналитики и внешнего сервера.

The extension stores its refresh preferences and domain exclusions with Chromium's synchronization storage. It requires tabs, storage, alarms and contextMenus permissions, but does not use host permissions, content scripts, or tracking services.Расширение хранит настройки обновления и исключения в синхронизируемом хранилище Chromium. Ему нужны разрешения tabs, storage, alarms и contextMenus, но не требуются host permissions, скрипты внедрения или сервисы отслеживания.

Refreshing can discard unsaved edits. Add sensitive work sites to exclusions. Automated regressions and ZIP integrity checks passed for v1.9; a separate installed-extension acceptance run in Comet is still pending. This is a GitHub ZIP release, not a browser-store listing.Обновление вкладки может привести к потере несохранённых правок. Добавьте важные рабочие сайты в исключения. Автоматические тесты и проверка ZIP для версии 1.9 пройдены; отдельная приёмка установленного расширения в Comet пока впереди. Это ZIP-релиз на GitHub, а не публикация в магазине расширений.
