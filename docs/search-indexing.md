# Search indexing — manual owner actions

The website deliberately does not embed analytics, webmaster SDKs or tracking scripts. Search-engine ownership and sitemap submission are external administrative actions.

## Google Search Console

1. Add `https://stanleyll0yd.github.io/` as an appropriate Search Console property.
2. Complete the ownership method offered for the property type without adding runtime tracking code to the site.
3. Submit `https://stanleyll0yd.github.io/sitemap.xml`.
4. After a localized `/en/` and `/ru/` migration is deployed, inspect representative pages and confirm canonical/hreflang interpretation.

## Yandex Webmaster

1. Add `https://stanleyll0yd.github.io/` in Yandex Webmaster.
2. Complete site verification without adding analytics or advertising SDKs.
3. Submit `https://stanleyll0yd.github.io/sitemap.xml`.
4. Review indexing diagnostics after material sitemap or localization changes.

## What not to add

Do not add Google Analytics, Yandex Metrica, tracking pixels, cookie banners, remote JavaScript or tag-manager code merely for indexing. Search Console and Yandex Webmaster do not require on-site analytics to submit a sitemap.
