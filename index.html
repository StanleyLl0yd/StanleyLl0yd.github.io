About

Independent developer building Android, web and desktop products end to end: product decisions, interface, application code, tests, release automation and the public presentation around them.Независимый разработчик, который делает продукты для Android, Web и Desktop целиком: продуктовые решения, интерфейс, код, тесты, автоматизацию релизов и публичную витрину.
