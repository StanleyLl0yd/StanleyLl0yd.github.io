What this site does

The page sends only the public Suno link you enter to our serverless backend. The backend fetches public metadata and the current Suno stream, decrypts it while transferring it, and stores nothing. Passwords, cookies and account tokens are never requested.

Limitations

Suno may change its public API or Mango stream format. If the current scheme changes, the site stops with an error instead of saving a damaged file.
